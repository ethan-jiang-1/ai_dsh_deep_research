# RFC：team-preflight 末标记加固（已知脆点收口）

> 状态：implemented
> 归档：2026-09-27

归宿：roadmap §队列「team-preflight 末标记加固」（2026-09-25 马拉松条目 2，已毕业离队）。

## 决定

`team-preflight-smoke` 的 lead 断言**判据改锚**：被测对象 = 机制完成——回合落定
（`waitForQuiescence` 锚定，日志行数连续轮询不变）+ 机制断言集（spawn_teammate ×2 /
list_agents / one-shot subagent 探针 / 成员响应，**全部保持不变**）；末标记「预检完成-LEAD」
降为**模型服从度观察点**——在场记 PASS 证据，缺席进 `findings` 观察清单、不再红灯。
未改 persona、未改 prompt（脚本本地 `LEAD_PROMPT` 本就命令式），故无 L4-lite 重跑义务。

依据：历史实测三跑两红一绿，红的全是标记缺席、机制面三次全 PASS——把"回合完成"寄托在
模型字面服从上是**断言设计错误**，不是机制问题。

## 实际跑过的验证（判据改锚后三连跑，真模型档）

| run | 末标记 | 机制断言集 | 结果 |
|---|---|---|---|
| #1 | **缺席**（旧判据下即红） | 8/8 全过 | ALL PASS |
| #2 | **缺席**（同上） | 8/8 全过 | ALL PASS |
| #3 | 在场 | 8/8 全过 | ALL PASS |

三连跑恰好复现历史 2/3 缺席率——改锚后缺席不再稀释该脚本作为真模型档回归的信号价值。
日志留档 `dev/smoke-workspace/team-preflight-reruns/run{1,2,3}-2026-09-25.log`（gitignored
运行区）。全链：24 门禁 + 28 tests 全绿。

## 输掉的方案

- **加大等待超时**：否决——抖动源是"模型不吐"而非"吐得慢"，等更久只掩盖；
- **重试到绿**：否决——把抖动洗成绿灯 = 掩盖真信号（verify the world 教义反面）；
- **删掉末标记断言**：否决——它是"lead 走完全流程"的最廉价指针，改锚（降为观察点）
  比重删好；
- **prompt 侧加固**（RFC 原列为辅选项）：未采用——改锚后三连跑已绿，prompt 已是命令式，
  再加码属过度工程；若未来观察点显示缺席率影响别的断言再议。
