## 决定

对照 company@59551f2 的 layering 四件套补齐三缺口（出处 = [company 钉版复核 Note](2026-10-09-company-repin-review.md) 候选③）：

1. **禁物判法两层化**：提及级 regex（child_process import / playwright / 密钥名 + credentials.yaml，任意提及即红——字符串常量与注释里的间接引用也咬；合法文本消费者走显式豁免表登记：deploy-bin = 部署安全边界契约、smoke-contract = 真模型档 closed set 契约，**执行面零豁免**）+ 解析级调用表达式（spawn/exec/fetch 族只认真调用，夹具字符串不咬）。解析器 = [lib/keyless-imports.mjs](../../scripts/lib/keyless-imports.mjs)——company tools/lib/keyless-imports.mjs@59551f2 近逐字移植（函数体零改动），typescript 作纯函数解析器。
2. **import 闭包图守卫**：从全部 test 文件出发跟随本地字面量 import（含再导出与动态字面量），闭包内违禁内置（child_process/http/https/net/dgram）与运行时调用零容忍——传递引入可见。驱动面 regex 禁令只列 `scripts/(smoke|probe|dist|verify)/`（设计上就要起进程/浏览面的目录，报因明确）；`run-gates/`、`run-ops/` 不列目录禁单，纯度由闭包图持续背书（探查实证两目录现员全纯）。
3. **test 命令钉**：`package.json scripts.test` 精确串断言（node --test glob 即发现配置，改宽/改坏即红）。
4. **纪律有家句**：tests/AGENTS 的分层句存在性断言（company it#4 同款）。

活暴露面三处**结构收口**（探查发现：卡上只知其一）——判据核心迁 `scripts/lib/`，驱动壳留原位、`readLog` 注入（company inspectKeylessGraph 的 injected readers 同型）：

- `lib/gates-cases.mjs` ← gates-smoke 的 CASES/CONTROLS + 纯 fs 注入手法（gates-smoke 瘦成驱动壳；mutate 后驱动统一 `git add -A`，案例函数零子进程）；
- `lib/node-gate-core.mjs` ← node-gate 全部判据函数与契约日常量（zstd CLI reader 留驱动壳注入；纯 reader 默认——.zstd 报线索后按空语料偏红）；
- `lib/evidence-audit-core.mjs` ← evidence-audit 的 auditBundle/buildCorpus/normalize 族（同上注入；reader 返回 null = 跳过文件）。

多帧拼接 zstd 日志继续走 CLI（探查核过 node:zlib 的 zstdDecompressSync——engines 允许的版本都在场，但多帧语义未证，不动解压实现）。tests 的 schema-scan/run-dashboard 消费保持原位（两文件全纯，闭包图背书，零搬迁）。

## 输掉的方案

- **手搓受限括号配对解析**（卡上原 fallback）：零依赖零加载开销，但边界形态漏判 = 假安全（守卫价值恰在"不漏"），且自造轮子违研发宪章"循而不发明"——输给 TS 解析器移植。卡上原"不采纳 typescript（违 keyless 纪律）"条目被探查证伪后经用户拍板推翻：company 的 keyless = 运行时禁子进程/网络/凭据，npm 解析库在其 keyless 缝隙合法存活；typescript@6.0.3 本来就是本仓 root devDep，非新增依赖；真实成本 = 回归加载（实测全套 layering 560ms，仍秒级）。
- **vendor 树内找纯 JS 解析面**（卡上候选）：grep 全 vendor 无 acorn/espree 级解析件；typert 是 build-time 类型图生成器非 import 扫描器——无线索，放弃。
- **目录级全禁（tests 只许 scripts/lib/）**：会把纯住驱动目录的 schema-scan/run-dashboard 消费也判红，逼出 ~700 行无谓搬迁——收窄为真驱动面四目录 + 闭包图兜底。
- **白名单豁免三暴露面**（关闭条件允许）：豁免是常驻债务（"import 进来会把 spawn 整条带进回归层"的风险靠承诺不靠结构）——输给判据核心迁 lib。
- **zstd 换 node:zlib**：多帧拼接语义未证，run 关键机械的行为风险不值——保留 CLI + 注入。

## 实际跑过的验证

反证（先红后绿，全部实跑，逐条记于卡）：

- 提及级：动态 import 形态（注释里 `await import('playwright')`）→ ①红"真浏览器"；密钥名间接引用（`const k = 'DEEPSEEK_API_KEY'`）→ ①红"回归必须 keyless"。
- 解析级反向：夹具字符串 `'fetch(https://…)'` → ②不咬（全套 5 绿——反向契约）。
- 驱动面：tests import `scripts/smoke/gates-smoke.mjs` → ③目录禁令红。

- 命令钉：scripts.test glob 改宽 → ④红；还原全绿。
- 案例表迁移回归：gates-smoke 的 `md-links-untracked` 案例在统一 add -A 下首跑失效（探针放 `runtime/` 根不受 ignore 被收进 tracked）——修案例探针到 `runtime/smoke-workspace/*`（真 ignore 路径）后复绿，即统一 add 方案自身被案例咬过一次红（案例表有效的活证据）。

搬迁正确性：node-gate/evidence-audit/gates-cases 判据核心迁移由既有夹具测试钉住（node-gate + evidence-audit + verify-gates + schema-scan + run-dashboard + run-fold 直跑 99/99）。
