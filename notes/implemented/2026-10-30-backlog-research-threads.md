# backlog research：以研究题（名头）为单位，题名页承载消费者与产出的卡

> 状态：implemented

> 来源：用户 2026-10-30 请求——两个 research README 下的内容要有「名头」；研究结束会产出 issue
> 卡，归档后仍按名头进子目录，今后归档与回溯才容易。授权原话 =「你的理解非常好, 你动手吧」。
> 规则正文 = [_backlog/research/README.md](../../_backlog/research/README.md) 与
> [_backlog/_archived/research/README.md](../../_backlog/_archived/research/README.md)；本篇只记为什么。

## 决定

1. **单位 = 研究题（名头）**：一个研究题 = 一个目录 `<slug>/` + 一张题名页 `README.md`；活跃在
   `_backlog/research/`，归档在 `_backlog/_archived/research/`；归档时整目录 `git mv`，slug 不变。
   研究材料不再允许平铺在 shelf 根——单份材料也住进题名目录。
2. **题名页承载四个事实**：问题、消费者、产出的卡、材料清单。消费者 = 谁委托 / 使用这轮研究；
   产出的卡 = 研究结束后由它新立的 issue / bug 卡。后者是「研究 → 卡」的反向线索；卡正文再链回
   题名页，形成双向可回溯。没有产出的卡写 `—`，不省略字段。
3. **归档索引一题一行**，不再逐文件铺表；材料明细、历史消费者与产出的卡住在题名页。归档 = 整目录
   搬迁 + 补 `> 归档：` 行；材料正文不重写，只修搬迁所需的相对链接。
4. **机械面**：`backlog-liveness` 检查——材料在题名目录内、题名页存在、题名被 shelf README 按目录
   点名、材料被题名页逐份点名、题名页 `> 问题 / > 消费者 / > 产出的卡` 三行在场。研究正文的
   `topic` / 一行 `intent` 与「不写 status」规则不变；归档研究正文的旧形态仍豁免。
5. **迁移存量**：14 个平铺文件并成 9 个题名目录；11 个既有目录补题名页（含原 `oss-dr-mining`
   题名页漏记的 `2026-10-06-oss-dr-followups.md`）。归档索引从 60+ 行逐文件表改为 20 行题名表。

## 输掉的方案

- **只在索引里加「名头」列 / 题头，不建题名目录**：回溯时仍要在 60+ 行里找；研究 → 卡的链仍散在
  多个文件行；归档搬迁仍按文件决策。名头会退化成表格里的一列文字。
- **一卡一题**：研究常服务一张卡却产出多张卡，或一张卡先后多轮研究；按卡切会把同一研究题拆散，
  且「研究 → 新卡」没有独立位置。
- **把题名 / 状态做成 research frontmatter 字段**：研究位置已经表达活跃 / 归档；再加 status 会制造
  第二个状态正本，且与「材料不写 status」的既有规则冲突。题名页是索引页，不是材料。
- **保留 shelf 根平铺单文件**：单份材料看似省一层，但归档区会重新退化成平铺堆，「归档后仍进子目录」
  的诉求落空；门禁也无法稳定区分「单文件」与「漏建题名页」。
- **只改 README、不加门禁**：约定会随下一次归档漂移；`backlog-liveness` 已有索引对账，扩展它比另造
  一套检查便宜，且反证可住同一案例表。
- **归档时拆开材料、只搬被引用的文件**：会让一个研究题跨活跃 / 归档两处，题名页的「材料清单」出现
  两个家；整目录搬迁才能保住 slug 与研究题身份。

## 实际跑过的验证

- **真树红→绿**：改门禁后先在真树跑 `pnpm verify`——`backlog-liveness` 报 28 处（14 个平铺文件 +
  10 个缺题名页目录 + `oss-dr-mining` 缺三行 / 缺 followups）；完成迁移与题名页后 `pnpm verify` 全绿。
- **门禁自测**：`node scripts/smoke/gates-smoke.mjs` 全绿——对照组零注入全 PASS + **94 个注入案例**
  均被点名报红；其中新增 7 个研究题案例（平铺 / 缺题名页 / 题名未登记 / 材料未登记 / 题名页缺字段 /
  归档平铺 / status 字段）。
- **契约测试**：`node --test tests/contracts/backlog-liveness.test.mjs` 17/17 通过——新增 5 条研究题
  契约（题名页 + 三行、shelf 根平铺、题名页 / 索引 / 材料清单、归档平铺）。
- **全量回归**：`pnpm test` 1005/1005 通过；`pnpm verify` 全绿（含 `md-links` 对搬迁后的入链对账）。
- **人工抽链**：`2026-10-29-method-library-workbench-redesign.md` → `method-library-cocreation/README.md`
  → 9 篇材料与 `ux/`；`2026-10-11-executive-research-ux/README.md` → 三张产出的卡；两者反向链均在场。
