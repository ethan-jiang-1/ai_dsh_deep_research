# implemented/ — 已交付决定（过去时，但活着）

> **时态：过去**（决定已经交付）。它是**活的决策记忆，不是冻结档案**：路径、名称、默认值
> 随实现同 diff 维护——但**不改写决定本身**。想逆转一个决定 → 写新 Note 并与之互链
> （取代规则见 [notes/README](../README.md) §决定覆盖与取代检查）。

## 主入口

目录树就是清单（`<首提日期>-<主题>.md`，按主题名检索或浏览）——**不建索引**，避免第二份
会漂移的清单。要找"某个机制为什么这样"，按机制名搜本目录；要找"现在是什么"，去 `docs/`。

## 进门与出场

| | 规则 |
|---|---|
| 进门 | RFC 从 `proposed/` 毕业（正文改写为已交付事实体），或用户直派任务交付的决定 |
| 骨架 | `## 决定` / `## 输掉的方案` / 实际跑过的验证 / 环境状态（guides/60 §4）；门禁生效前的遗留形态标 `<!-- grandfather: … -->` |
| 维护 | 事实随实现同 diff 更新；**逆转走新 Note + 互链**，不改写旧 Note 成相反结论 |
| 出场 | 只经完整取代（新 Note 吸收全部独有内容后）才可删；未来指导价值低者迁 `archived/` 冻结（进门判据 = [notes/README 差异表](../README.md)） |
