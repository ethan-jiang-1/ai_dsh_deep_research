## 时态与职责

过去，但活着。放“为什么这样决定、输掉了什么、实际跑过什么验证”。它是**决策记忆**，不是当前
合同，也不是事故叙事（→ [notes/README §事故复盘](../README.md)）。

## 只收 / 不收

- 收：已交付的持久决定 + 真实备选 + 当时验证 + 环境状态。
- 不收：当前是什么（→ `docs/`）、未决提案（→ [proposed/](../proposed/README.md)）、
  否决（→ [rejected/](../rejected/README.md)）、事故复盘（→ [notes/README §事故复盘](../README.md)，
  冻结在 archived/）、纯机械/局部编辑。

## 进门与出门

- 进门：RFC 从 `proposed/` 毕业（正文改写为已交付事实体），或用户直派任务的交付。
- 出门：被完整取代且独有内容已吸收 → 删；不再指导未来、无需再解释 → [archived/](../archived/README.md)；
  仍指导当前工作 → 留。
- 骨架与状态：`> 状态：implemented`；`## 决定` / `## 输掉的方案` / 实际跑过的验证；
  遗留形态标 `<!-- grandfather: … -->`。

## 维护（活记忆）

- 事实（路径、名称、默认值）随实现同 diff 更新；**不改写原决定**。
- 被后续决定推翻 → 旧篇头部加 `> 历史注记：<阶段/机制>；<被谁取代 / 现行看哪>`，与新篇互链；
  不要改写成相反结论。
- 「实际跑过的验证」按当时原样保留（命令、路径、计数是历史证据）；它与当前事实冲突时，
  以决定/指引段 + `docs/` 为准。
- 不建索引；按机制名检索。

## 阅读契约

先读头部历史注记。只把它当“为什么”，不把它当“现在是什么”；要做当前决定，去 `docs/` 与源码。
