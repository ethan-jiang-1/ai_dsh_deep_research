## 这一弧修掉了什么（机制级，非全量流水——流水在各 commit）

**审计工具**（`evidence-audit.mjs`，从"会撒谎"到可信）：整条崩掉（V8 字符串上限）→ 语料**自证**
（吞掉 write/read 事件 = 拿卡片自己证明自己，任何放宽都会满堂红）→ web-only 语料；URL 判据
三档 + host 比较 + 反斜杠/引号/转义剥除；source_url **抓取强度**（搜索结果里出现过 ≠ 抓过）；
final.md 缺席从静默跳过改 fail-loud（防空语料）+ 位置违约单列。preset-smoke 端口泄漏（web 进程
不在 spawn 进程组里）按端口收割。

**HITL 代答**（`dev/hitl-answer.mjs`，从不存在到稳定）：answerer 只在浏览器客户端（无 CLI/RPC）
→ 真浏览器驱动；自身修掉 7 处（`--` 重复、盲点 Continue、`_dialog_` vs `_mask_`、click 超时静默
吞、Recommended 误命中推理文本、超长卡视口外 + DOM 原生点击兜底）；模式自报（dry-run 教训）。

**契约**（判据正本 = 研究手册）：摘录最小契约四条（引文行只放原文 / 逐段逐字 `[…]` / 表格逐格 /
source_url 必须真抓取）；**日期最小契约**（落笔前跑 `date`——模型时间感五场全错）；final.md
钉死 run 根。

**角色方法论**：critic 轻量模式（quick_factual 配轻量 critic，消除 lead 自检弱面）+ 全模式抓取
底线 + 说明落点纪律（修复轮要求的注解不进引文行）+ **出处链 = 独立重抓**（验证内容真实支撑，
比脚本更硬的判据）；scout 检索器对账（单一可达标"单检索器——待破"）；lead 组队矩阵与交付前
溯源自审。

**一条重要的负结果**：角色会话（含子代理）**没有任何命令执行能力**——我曾让 lead 派子代理跑
审计脚本，实测跑不了（子代理把脚本当文件读了一遍然后如实报告"无 shell"）。机械审计因此是
**操作侧**仪器；会话内的等价物 = critic 独立重抓（第八场重抓 23 URL、比对 340 格，0 误差）。

## 平台期判定：**到达**

判据（事先声明）：连续深度 run 全绿且**无新缺陷类别**。第七场（57 卡，最大规模）：日期 0 错、
final 位置正确、链 201/201、CRITICAL 0，仅 source_url 残留 2 张（**已知类**的执行方差，非新类别，
且 critic 重抓机制当时尚未显式化）；第八场全部为 0。逐场未再出现新类别——第六/七/八场暴露的
问题全部是已知类或工具侧（hitl-answer 视口问题，已修）。

**为什么停在这里**（再往下很难做的理由）：
1. 残余项全部是**已知限制且有防御**，不是未发现的洞（见下）；
2. 防御已五层：analyst skill → critic 独立重抓 → lead 交付前自审 → 操作侧机械审计 → 观察面
   （仪表盘/audit.md 对用户可见）；
3. 唯一未在 50+ 卡规模验证的机制（critic 重抓下 source_url=0）在两场薄 run 验证过（各重抓
   20+ URL）；若要规模复验，一场 run 即可，但机制已证、趋势单调（3→2→0），边际信息量低。

## 输掉的方案（含已知限制——每条都是主动放弃或如实认输，防重开讼）

**主动放弃的方案**：

1. **检索器对账的字面格式**（放弃收紧措辞）：概念落地（scout 自披露检索器盲区、"自报/第三方"列、单一可达标注），
   但真实 run 里不用 `- 检索器:` 字面字段（探针里用）；两场深度 run 一致——按"概念达成、格式
   自适应"记档，不再收紧措辞（格式警察的边际价值低于 scout 的排版自由）。
2. **摘录审计的机械极限**：spill 截断件的尾部（日志里按构造缺席）、带 markdown 链接的原文行
   （渲染形态不同）——机械对不上 ≠ 伪造（critic 重抓已覆盖实质）。
3. **web_search 上游间歇故障**：两场 run 命中（4 调 0 成）；agent 的降级行为符合设计（直接打
   域名 + 显式披露盲区）——环境问题，非仓内缺陷。
4. **会话内跑审计脚本**（第八场实测否决）：角色会话无任何命令执行能力，子代理把脚本当文件读了也跑不了——机械审计留在操作侧，会话内等价物 = critic 独立重抓（更强判据）。
5. **规模方差**（如实认输不追零）：source_url 在 50+ 卡下 2/57 的残留（第七场，早于 critic
   重抓显式化）——已知类，四层防御在场，audit.md 如实点名；判据是「无新类别」不是「零瑕疵」。
