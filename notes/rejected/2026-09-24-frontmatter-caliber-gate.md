# 否决：给 evidence frontmatter 加 caliber 字段并机械断言

> 状态：rejected — margin ≠ threshold：实测前别上 gate（口径纪律定案时用户批准的范围 =
> 纪律文本先行；基础整治 §3.4 用户拍板从 data-caliber RFC 迁出独立成篇）。

## 原方案

在证据 frontmatter（`source_url / retrieved_at / quality / found_by / supports` 之外）
新增 `caliber` 字段承载口径信息（测量条件），并加机械断言（字段缺失即红）——把
"口径最小契约"（数字/规格类摘录须带测量条件 ≥2 项）从纪律文本升级为机器可查。

## 否决理由

- Q6 已登记"floor 数值门禁缺实测证据"——同一病根：没有真实 run 的质量分布，任何
  数值门禁都是拍脑袋。**margin（纪律文本，人判）≠ threshold（机器判）**，先跑实测；
- 口径的"两项测量条件"是散文判断（版本/配置/时间/原文限定语的组合千变万化），
  机械断言只能查"字段在场"，查不了"口径真实"——在场断言对语义约束是假牙齿
  （"措辞与机制强度脱节"同款病，研究手册 §证据文件契约·机械强度诚实记账）。

## 复活条件

首个完整研究 run 实测出现：口径缺失高频导致 critic 狩猎漏检，或"口径不明"标记被
滥用逃避纪律——且实测数据能定出合理判据形状时，随 Q6（floor 机械化）一并重提。
