## 问题

run 交付 ≠ 条目完成：判据证据、销账、复盘、打扫、M3 重排全部欠着；不收口 = 队列堵死、
M3 无起点、事故教训蒸发。

## 方案（收尾清单，run 交付后同 diff 执行）

1. **L4 四判据证据 Note**（含通道错位事故完整叙事：三段注入面事故链——化石镜像 →
   pack 文本 → 旧会话复用——+ 各自处置 + 机制化归宿）；
2. **Q2/Q4/Q5/Q6 销账**：答案 + 证据进 00-index 待定表（销账注记样式 = Q1/Q3 先例，
   销不掉的带证据留案）；
3. **company D18 复核结论**：team 语境下成员 subagent one-shot 可用性——以 A 系
   teammate 会话日志为证；
4. **搁置池三条复活条件复审**（专职 synthesizer=Q4 / floor 机械化=Q6 / UI 皮肤=run
   通过+demo 需求）；
5. **实测新发现 → 队列新条目**（已知至少一条：化石时代 five-file 布局与十件套契约的
   skill/模板差距评估）；
6. **打扫**：dev home 磁盘残留、run 留存策略执行（runtime truth 不进 git，Note 记
   路径与抽查结果）；
7. **M3 重排**：按实测证据定观察面 GUI 化等条目的优先级与次序（重排结果进 roadmap）；
8. **docs 面改动 → 入口链探针**（entry-chain-probe 首跑，或语义版人工一遍）。

## 输掉的方案

- **拆散到多 commit/多天收**（否——收口 = 同 diff 一次闭齐，散收必漏项）；
- **收口中发现的问题当场修**（否——收口是记账不是开发；新发现只登记进队列）。

## 验收判据

- roadmap 条目 1（首个完整研究 run）与条目 2（M2 收口）双双离队，对应 RFC 毕业
  implemented/；
- 00-index 待定表 Q2/Q4/Q5/Q6 全销账或带证据留案；
- M3 重排落进 roadmap（含观察面 GUI 化的新优先级）；
- 工作树净 + 15 门禁 + 20 tests 绿 + 探针跑过。
