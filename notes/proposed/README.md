# proposed/ — RFC 停机坪规则

> 这里放**队列条目的全文 RFC**（一文件一条目：问题/方案/输掉的方案/验收判据）。
> 队列行（roadmap §队列）只有排序与指针，发现与状态分家。

## 规则

1. 进门条件：roadmap §队列有对应条目（verify 门禁 proposal-scheduled 强制）；
2. 毕业：条目收尾时 RFC 迁 `notes/implemented/`（日期+主题命名），队列行删除；
3. 状态行写在 RFC 自己头部（proposed / approved / superseded），不写进 roadmap；
4. 落地次序住队列行：多条 RFC 服务同一队列条目时，次序登记在该队列行——本目录按
   文件管理，文件名不携带次序（从名字看不出先后，以队列行为准）。
