# RFC：floor 数值门禁机械化（质量下限的机械断言）

> 状态：proposed

归宿：roadmap §搁置池「floor 数值门禁机械化」（Q6 已销账：**维持搁置**，证据在案）。

## 问题

质量门目前是 Critic 的散文审查（声明式质量门，D4/D5）。是否需要给报告加数值 floor
（如"来源数 ≥ N"、"每结论至少 1 引用"的机械断言）防质量滑坡。

## 现状证据（2026-09-25 首个完整 run 实测，Q6 销账）

**不需要**：critic 散文审查实际抓出三根钉子（"2–4 年"无来源 / "1.56×"平台不对称 /
"国产高 16%"口径）——这就是质量证据；数值 floor 反而有假绿风险（凑数达标 ≠ 真溯源）。
出处同 [m2-run-mechanics §实施记录](../implemented/2026-09-24-m2-run-mechanics.md)。

### 重估追加（2026-09-26，两场 run）

第二轮证据：`drt_cn-llm-deep-research` 的 critic 首轮抓 1 条 CRITICAL、`drt_cn-llm-infra` 抓 5 条，
**两场全部闭合且终判 readiness = PASS**——即散文审查既抓得到问题、也没有出现"抓不完"的滑坡。
**结论不变：不引入数值 floor，维持搁置。**
第五至八场再重估（含 40 / 57 卡最大规模）：critic 在第五场抓 4 个 CRITICAL（含"报告方法学结论被
自身证据证伪"级）、第七场 FAIL→PASS 走满四轮、第八场 0 CRITICAL——散文审查持续有效，且无任何
滑坡迹象。

## 方案（草图，仅复活后适用）

若多 run 出现滑坡实证：floor 只做**窄面机械哨兵**（如 final.md 的 [来源: …] 链接密度、
evidence frontmatter 五字段完备率——与 evidence 身份链同源），不做内容质量judgment
（那归 Critic）。

## 输掉的方案

- **预防性上 floor**：已否决（Q6）——keyless 断言假绿风险 + 实证无需求。

## 验收（= 复活条件现状）

- 复活条件：run 出现质量滑坡实证（**✗ 未观察到**；「研究类型覆盖」多 run 后重估）；
- 复活后验收：floor 门禁带红证（注入缺来源结论 → 红）+ 不误伤合规报告。
