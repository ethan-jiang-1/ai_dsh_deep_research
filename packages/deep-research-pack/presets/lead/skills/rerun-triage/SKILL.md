# rerun-triage — 不满转接（用户说法 → 我们的手段）

**何时加载**：用户对当前或已交付的报告说「不满意 / 再深一点 / 不是我要的 / 太长了 / 我不信」，
或要求「改一下」时——**先加载本 skill 再回话**。交付前的 HITL2 卡与交付后的补改都适用。

**它不做什么**：不新增交互点（仍是 HITL1/HITL2 两个停靠点）、不做关键词路由、不在观察面加按钮、
不擅自 rerun。分诊只决定「怎么回、给几个手段、代价说清」，动手要用户点头。

## 词表（单一正本）

| 用户可能怎么说 | 诉求类别 | 手段 | 产出 / 代价 | 什么不变 |
|---|---|---|---|---|
| 太浅 / 只有二手 / 关键数字没有 / 我不信这条 | 证据不足 | **补研究**（同 bundle 证据扩张） | `final/vN+1`，重入挖掘；按报告末节范围再跑一轮抓取 | 问题定义、已有证据、旧版本 |
| 方向不对 / 我要的是 X 不是 Y / 范围错了 | 方向变了 | **另起一个 bundle**（结构性重跑；sibling 预检 + 用户同意） | 新 `drt_<slug>`；成本≈一场新 run | 旧报告与其版本账原样保留 |
| 结论跟我知道的不一样 | 反证缺失 / 口径错 | 先定位「哪条结论 vs 哪条证据」（critic 升级或定向反例），再决定是否补研究 | 可能只补一条证据，不重写全篇 | 其余结论 |
| 数据过时了 / 时间口径要改 | 时效 | **补研究**（时效刷新）+ 口径行更新 | `final/vN+1` | 结构 |
| 太长 / 太绕 / 要一页纸 / 要表 | 表达形态 | **表述修订**（原位改） | `final.md` 改，版本不变 | 证据与结论 |
| 来源不合规 / 只要官方 | 来源约束 | 运行中 = **steer**；已交付 = **另起一个 bundle**（约束变了） | 视时点 | — |
| 过程我不放心 / 为什么停在这 | 不是 rerun | 走状态页 / §Decisions / 审计，不重跑 | — | 全部 |

## 五条纪律（对话程序）

1. **先复述再分类**：用一句人话回述「我听到的是证据不够，不是方向错」，让用户能当场纠正。
2. **至多两个手段 + 一句「这个不用重跑」**：超过两个选择 = 把分类推回给用户；「表述修订」通常就是
   那句不用重跑的。
3. **范围只从报告来**：补研究补哪块，引 `final.md` 末节「下一版优先项」/ findings gap / review 残留，
   不现场发明范围。
4. **不动手**：分诊只给方案与代价，用户点头才落；点头后按 D17 三形态走，第一动作仍是回写
   §Decisions。
5. **不自动分类**：不做关键词/正则路由；分类住你，机械面只保证三种后果与版本记账可见。

## 回话模板（短，别写小作文）

- 「你这条更像**证据不够**（不是方向错）：我可以**补研究**——按报告末节第 N 条补一轮，出新版本 vN+1；
  或者只**改说法**，版本不变。要哪个？」
- 「你这条是**方向变了**：要**另起一个 bundle** 重做（旧报告原样保留，成本≈一场新 run）。
  确认的话我先做 sibling 预检再开。」
- 「这份**太长**：**表述修订**就行，原位改、版本不变，不用重跑。」

## 交付后入口

状态页 ⑤ 与终稿页脚有只读折叠块「还不满意？三种改法」，三行各带一句可复制的话；用户照抄发给你，
你按本表分诊。观察面只给话术，不按钮化 rerun（D18 只读）。

## 边界

- 报告末节是「下一版的候选」，不是承诺；写不进就标「未取得」。
- 方向变化不重开 HITL1；结构性重跑另起 bundle。
- 用户只说「不满意」而没说哪里不满意时，**最多问一个带范围的问题**（「是深度不够、方向不对，
  还是太长？」），不要连问。
