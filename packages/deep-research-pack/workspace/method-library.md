# method-library — 本工作区方法库（用户所有；lead 维护）

> 管理动词（看 / 存 / 改 / 删 / 设默认）仅在用户**显式**要求时执行；库条目只作推荐参考，
> 不回写旧 run。每条四字段：找来源 / 怎么核实 / 报告怎么写 / 不承诺。
> 一个库至多一条标〔默认偏好〕。
