## 研究问题

1. 一个研究方向独立成题的判据是什么（问题、消费者、产出卡、材料）？什么该合并、什么该拆？
2. 题名页与材料的分工：哪些内容进题名页（名头 / 边界 / 索引），哪些进材料（证据 / 推演 / 结论）？
3. 结论如何不烂在 research 里：什么算「已定性」、什么必须转 issue / note、什么只进 commit？
4. 材料性判据（借 company 的 materiality）：哪些研究结论必须留 Note，哪些 commit 即可？
5. 当前门禁（`backlog-liveness`）只查结构；缺的「材料被引用 / 结论被消费」的证据该怎么补，还是不该补？
