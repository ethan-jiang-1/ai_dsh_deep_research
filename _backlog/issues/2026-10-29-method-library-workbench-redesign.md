# 方法库工作台重排：两视图（库 + 工作台），草稿卡在上、对话在下

> 立卡：2026-10-29 ｜ 状态：推敲中（用户已选 A；待落地）｜ 类型：Feature ｜ 结论倾向：现在做 ｜ 可关闭：否

## 背景

方法库页现在是「库 / 表单 / 方法编辑」三列并排（`data-method-library` 三栏）。用户反馈两件事：
1. 三列拥挤：表单被挤到约 1/3 宽，方法编辑 380，库 270；一对话就看不见成果、一改表单又看不见对话。
2. 滚动错位：整页/view 会整体滚，三栏没有各自独立滚动。

已出 A/B 两套 SVG 方案（`_backlog/research/method-library-cocreation/ux/`，说明 `2026-10-29-ux-redesign.md`）。**用户选定 A**：

- **两视图**：左「库」+ 右「工作台」；工作台里只有两块——**草稿卡（上）** 与 **方法编辑对话（下）**，没有第三列；
- 草稿卡 = 名称 + 四字段 2×2 + 进度 + 来源标 + 保存 + 展开表单；
- 对话 = 满宽、完整历史、起手式、输入、自动贴底；
- 整页不滚；卡与对话各自滚；「展开表单」把卡变成全表单（对话收起），「回到对话」收回。

## 目标

1. 页内只有两列（库 240–360 可拖 + 工作台吃满）；
2. 工作台 = 草稿卡 + 对话（竖向），两者都满宽；
3. 整页/view 不滚动；卡、对话各自滚动；
4. 所有既有能力保留：起手式三路、一次一问、字段级回填、手改/撤销、进度/来源、撞名确认、保存封套/回执/回读、读态编辑/删除/设默认、降级、空态；
5. 卡与全表单共用同一份 draft 与同一组 change handler，绝不出现两套状态。

## 交互流程（新建 → 保存）

1. 点「新建」→ 左库不动，右工作台出现空草稿（名称待定、四字段待定、0/4），对话区出现起手式；
2. 选起手式（从零 / 照内置 / 从最近 run）→ 方法编辑发第一问（先定场景）；
3. 用户答 → 方法编辑消化 → 草稿卡对应格出现内容、标「来自对话」、进度 +1、下一问；
4. 循环到 4/4 + 名称有值；
5. 点「保存到方法库」→ 保存封套 → 方法编辑调 `method_library_upsert` 写库 → 页面回读核对 → 回执「已落盘核对通过：<名称>」；
6. 读态：卡只读，出现「和编辑聊聊 / 删除… / 设为默认」；对话收起；
7. 中途手改：标「手改」、900ms diff 发方法编辑、可「撤销对话更新」；撞名保存前确认；方法编辑不可用 → 表单照常 + 明确提示。

## 状态呈现（验收按这张表）

| 状态 | 左库 | 草稿卡 | 对话区 | 页头/回执 |
|---|---|---|---|---|
| 新建空态 | 不动 | 四字段「（待定）」、0/4、保存按钮弱化 | 起手式 + 第一问 | — |

| 失败/降级 | 不动 | 表单照常可填 | 顶部「方法编辑暂不可用」 | 回执说明原因 |

## 布局细节

- 页头：方法库 + 「本工作区共享 · 保存交方法编辑」+ 刷新 + 新建；
- 左库：我的库 / 内置参考 / 搜索 / 条目列表（空态、内置参考列表）；宽 240–360 可拖；
- 草稿卡：名称、四字段 2×2（字段值截断 + 「展开表单」看全文）、进度 n/4、来源标、设为默认勾选、保存、展开表单；
- 全表单模式：字段全宽 textarea、Markdown 预览、保存、取消、回到对话；
- 对话：标题「方法编辑」+ 说明；起手式三胶囊；问题/回答气泡；问卡；状态行（正在输入/已停止）；输入框；自动贴底、上翻暂停；历史保留；
- 主题：全部 `--dsw-alias-*` token；不硬编码颜色；
- 滚动：`[data-method-library]` 填满 tab、`overflow:hidden`；卡与对话各自 `overflow-y:auto`。

## 落地拆分

- **P0 结构**：两列骨架 + 草稿卡 + 对话区（复用现有 `MethodCoachPanel`）+ 页不滚/各栏滚；
- **P1 状态贯通**：卡与全表单共用 draft/change handler；active/来源/进度/手改/撤销在卡上成立；
- **P2 保存/读态**：卡上的保存 → 封套 → 回执 → 读态；读态的编辑/删除/设默认；
- **P3 模式切换**：「展开表单 / 回到对话」；对话收起/展开；读态默认收起；
- **P4 边角**：撞名、降级、空态、从 run 三条、内置参考；
- **P5 验证**：keyless（draft 合并/写库/解析）、真模型 probe（新建→四字段→保存→已落盘）、client-load、`pnpm verify/test` 全绿；更新 design/40 与 pack README；SVG 证据归档。

## 非目标

- 不做 B 的抽屉方案；
- 不合并 `spike/method-coach-embed`；
- 不改 method-editor preset / 窄工具语义（写库、删库接口不变）。

## 验收

1. 页内只有两列；工作台内只有卡 + 对话；任何一栏都不整体滚；
2. 新建→起手式→第一问→回填一格→进度/来源/active 正确；
3. 手改不被覆盖、可撤销；撞名有确认；
4. 保存→回执→读态；读态可编辑/删除/设默认；
5. 方法编辑不可用时表单照常；
6. 深浅色都跟随系统；
7. `pnpm verify` / `pnpm test` / 真模型 probe / client-load 全绿。
