## 2. 系统视角：上一批的两个类级缺口

### 2.1 守卫夹具 ≠ 真实产物（352）

`final-target.spec` 的 `canonical()` 手写了 `slug:'x'`，于是「回执 slug 是 `drt_x`、调用方是裸 `x`」这条真实边界从未被测。**修法不是只加一个 `replace`，而是让夹具从生产者产物来**：fixture 用 `run-accept`/`buildDelivered` 的真实输出（`slug:'drt_x'`），调用方用驾驶舱实际参数（裸 `x`）。

### 2.2 同一 fold，两个输入集（351）

`runHealthOf` 对「任何带时间的事件」更新活动时间；durable log 与 follow 快照不是同一事件集（打开会话注入的生命周期事件只在前者缺席）。两个 oracle 因此对同一会话给出不同结论。**修法 = 活动谓词显式化 + 同输入集对账**；另外补时间推进面（`now` 不能冻在 `useMemo` 里）。

### 2.3 时间谓词的通用缺口（351 次因）

任何带 `now` 的观察面判据都需要一个推进触发；静态一次求值会让阈值在观察期间永不跨过。这是可复用的规则，不是 351 的局部补丁。

  - 同源对账：`watch-run` 与 `stalledBannerLine` 对同一事件集/同一 `now` 一致（在批 Note 的卡→case 表登记）。
- 浏览器：用 351 的合成会话（`runtime/e2e/check-status.mjs`）复验「打开即显示横幅」；主机 load 不允许则 NOT-RUN 并保持 `修复落地`。
