# suspended_issues/ · 暂停的推敲卡（暂停非完成）

> 从 [`../../issues/`](../../issues/README.md) `git mv` 迁入：**用户明示**「先放一放、没到
> 已结」的卡——暂停既非完成也非删除：上下文、风险与重启条件随卡走。文件名不变、内容
> 不重写、**状态行不加毕业判断**（没有判断落地）。规矩手册 = [`../../README.md`](../../README.md)。
>
> **纪律**：暂停需有用户明示或记录中的明确裁决；代理不得仅凭「觉得不活跃」
> 挂起一张卡。重启 = `git mv` 回活跃区，并按记录的重启条件重新判断；已裁决的 do-later 不住这里，
> 裁决 Note 是其事实 owner。
