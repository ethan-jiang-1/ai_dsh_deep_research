# lens 目录草案（8 条）

> 性质：草案，不是已发布合同。字段定义、选择规则与覆盖判据的正本 = [2026-11-10-lens-as-data.md](2026-11-10-lens-as-data.md)
> （v2 §3–§6）；本文件只负责「八条面具体写什么」。
> 实施时：每条落成 `packages/deep-research-pack/content/lenses/<id>.md`，字段名与本节标题逐字一致；
> 本文件把 8 条放在一起便于对账，落地时**每条单独成文件**（标题用 `# <id> — <name>`，删掉本节
> 序号），不要整份复制成一个文件；题型默认集不复制到这里（正本 = v2 §5.1），避免两处漂移。

## 格式

```markdown
---
id: <kebab-case，与文件名同>
name: <中文可读名>
---

# <id> — <name>

- **when**：...
- **seek**：...
- **verify**：...
- **frame**：...
- **refuse**：...
- **bias**：...
- **blind_spots**：...
- **pairs_with**：`<id>`、`<id>`      # 可选
```

**硬约束**（目录 test 守）：`id`/`name` 在场；`when`/`seek`/`verify`/`frame`/`refuse`/`bias`/
`blind_spots` **七个字段行**在场（行首 `- **<field>**：`）；`pairs_with` 里的 id 必须在目录内；
正文不出现「你是」「你的职责」；`id` 唯一且 = 文件名。

## 1. official — 官方口径

- **when**：状态、价目、规格、规则、主体信息；P1/P2 默认面。不用来判断真实使用效果、执行偏差、
  动机；不用于预测。
- **seek**：主体自己的官方域清单——官网/文档/定价页/公告/changelog/release notes/registry/
  status page/财报/法务页。注意区域站（.cn/.ai）与开发者站分家；用官方 `llms.txt`/sitemap/
  更新记录发现页面，不靠搜索引擎猜。
- **verify**：逐字摘录；带版本/条款/生效日/适用主体；同域多页互证（定价页 vs 文档 vs 公告）；
  `source_url` 必须真抓；区分「发布 / 生效 / 可用」；官方自述 ≠ 第三方验证。
- **frame**：「官方怎么说、何时生效、适用谁」；引用给页面/条款/日期；官方未披露就写「官方未披露」。
- **refuse**：不推断采用度/动机/执行强度；不把营销页或帮助中心软文当条款；不把官方未披露
  说成不存在。
- **bias**：高估「写下来的规则 = 实际执行」；高估最新文档覆盖全部历史/区域。
- **blind_spots**：真实使用、隐藏成本、执行偏差、非官方生态、未发声主体。
- **pairs_with**：`practitioner`、`quant`。

## 2. quant — 数字与口径

- **when**：价格/性能/规模/成本/份额/比率；P2/P5/P6 默认面。不适合没有数值的定性判断，
  也不适合把不可比数字硬比。
- **seek**：官方价目/规格表、财报、统计机构、基准原始结果（论文/仓库/leaderboard 的原始表）、
  账单/用量页；先找「分母/单位/口径」定义页；第三方榜单只作线索，不作承重。
- **verify**：单位/币种/档位/时间/版本对齐；逐格摘录；区分标价/实付/含税/折扣；自己算一遍；
  同一数字至少两源或标 `单源——待破`；区分厂商自报与独立测量。
- **frame**：表格 + 口径列 + 抓取时间；比较前先对齐；不可通约写「不可通约」，不硬换算。
- **refuse**：不把厂商自报当独立测量；不把点估计当区间；不做无数据估值/预测；不把相关当因果。
- **bias**：高估可量化项；忽略不可量化的成本/摩擦；被「精确数字」迷惑。
- **blind_spots**：定性因素、执行摩擦、未统计群体、长期变化。
- **pairs_with**：`adversarial`、`practitioner`。

## 3. practitioner — 一线实践

- **when**：采用度、真实体验、迁移成本、坑、组织约束；P3/P5/P6/P7。不适合问「官方规则是
  什么」或「总体比例是多少」。
- **seek**：社区/论坛/Issue/PR/迁移指南/招聘/真实账单/用户复盘/独立评测/会议分享；按
  「谁在什么场景遇到什么」找；排除厂商软文、SEO 农场、同一通稿的转载链。
- **verify**：多源独立（不同社区/公司/时间）；区分「有人说过」与「普遍」；找失败/迁移/弃用
  案例；看版本与日期；截图/日志/可复现步骤优先；样本偏差显式写。
- **frame**：按场景/角色/规模分节；引用原话；标样本来源与偏差；不把个别当总体。
- **refuse**：不推断总体比例；不把热帖当统计；不替用户做偏好选择；不把「社区没提」当不存在。
- **bias**：高估活跃发声者（抱怨者/爱好者）；低估沉默的大多数；样本自选。
- **blind_spots**：官方规则、未发声企业、长期演化、统计代表性。
- **pairs_with**：`official`、`quant`。

## 4. adversarial — 反例与证伪

- **when**：断言验证、尽调、争议题、任何要下结论的题；P4/P6 默认面。不适合纯描述、无 claim
  的地图。
- **seek**：反例词（失败/批评/诉讼/召回/下架/撤回/更正/处罚）、竞争假设、独立审计、监管处罚、
  历史反转、对手方说法；ACH：先列竞争假设，优先找能区分假设的证据。
- **verify**：每条关键 claim 专搜一轮反例；找不到记「已搜反例，未见」；区分「没有证据」与
  「证据不存在」；看反例的质量/时效/独立性；不把单一反例当推翻。
- **frame**：单列「最强反证」与处置；冲突不平均；未解决进「目前不能判断」。
- **refuse**：不把「没搜到反例」当「已证真」；不预设真伪；不把噪声当信号。
- **bias**：高估反例的代表性；把确认偏误过度矫正成「一定有黑幕」。
- **blind_spots**：支持面、正常路径、正面证据、确实成立的情况。
- **pairs_with**：`official`、`quant`。

## 5. structural — 结构与格局

- **when**：领域全景、对比、尽调；问「谁在哪、关系如何、价值怎么分布」；P3/P5 默认面。
  不适合单点事实或时间点状态。
- **seek**：产业链/价值链、市场份额、玩家清单、监管架构、标准组织、开源生态、依赖图、
  招股书/行业报告；官方 + 第三方 + 图谱三路。
- **verify**：先定义市场/子域边界；份额口径；关系要有出处；避免把名录当结构；两个独立来源
  交叉；标时效。
- **frame**：地图/分层/关系；标边界与时效；列「未覆盖子域」；不排唯一名次。
- **refuse**：不把地图当预测；不把未列出当不存在；不给无场景的选型建议。
- **bias**：高估可见玩家；忽略长尾/非市场化主体；静态快照。
- **blind_spots**：动态变化、个体体验、数字细节、执行摩擦。
- **pairs_with**：`historical`、`practitioner`。

## 6. historical — 时间与演化

- **when**：事态跟踪、时间线、演化；问「怎么走到今天/何时变的」；P8 默认面。不适合问
  「现在是什么」。
- **seek**：changelog/release notes/公告/监管生效日/历史网页（archive）/诉讼记录/年报/
  版本 tag；先钉时间窗与起点事件。
- **verify**：每节点有日期 + 出处；区分公告/生效/实际可用；archive 验证旧状态；时间线不靠
  记忆；趋势与事实分句。
- **frame**：时间线 + 当前截点 + 趋势（标「判断」）；节点带日期/出处；每个「现状」标截至时刻。
- **refuse**：不做无时间窗预测；不把公告日当生效日；不把趋势当事实。
- **bias**：高估近期事件；线性外推；忽略回退/中止/并行分支。
- **blind_spots**：当下状态、未来、未记录的变化、非官方采用。
- **pairs_with**：`official`、`structural`。

## 7. regulatory — 监管与合规

- **when**：受监管行业（金融/医疗/数据/电信/能源/跨境）、许可/备案/处罚/合规；P6 受监管时
  默认加面。不适合无监管约束的纯技术题。
- **seek**：法规原文/监管指南/处罚案例/许可目录/标准（ISO/NIST）/法院判决/生效日公告；
  按法域与义务主体分。
- **verify**：条文级引用（条款号/版本/生效日）；区分法律/指南/草案/征求意见稿；法域与主体
  范围；执法案例 vs 纸面规则；上位法/下位法。
- **frame**：按法域/义务主体/时间线；条文 + 执行状态；不确定标「草案/未生效」。
- **refuse**：不提供法律意见；不把草案当现行法；不推断执法强度或豁免适用。
- **bias**：高估成文法、低估执法与豁免；高估单一法域。
- **blind_spots**：行业实践、执法裁量、非监管约束、跨法域冲突。
- **pairs_with**：`official`、`practitioner`。

## 8. academic — 学术与方法

- **when**：方法/方案指导、需要理论依据或严谨评估；问「有什么证据/方法」；P7 默认面。
  不适合时效强的价格/状态/产品可用性。
- **seek**：同行评议论文/会议/综述/预印本/标准/系统综述；Google Scholar/ACL/arXiv/期刊/
  引用链；看复现与基线。
- **verify**：区分预印本/同行评议；样本/基线/效应量/置信区间；复现；利益冲突；不把单篇当
  共识；系统综述优先。
- **frame**：按证据强度分级；方法/局限/适用条件；引用原文；标「证据不足」。
- **refuse**：不把预印本当定论；不把相关当因果；不给临床/法律建议；不外推到不同人群/场景。
- **bias**：高估已发表/显著结果（发表偏倚）；低估工程实践；过时。
- **blind_spots**：一线可用性、最新产品状态、成本、实施约束。
- **pairs_with**：`practitioner`、`quant`。

## 配对图（用于 §5.5 的盲区处置）

| lens | 主要配对 | 接住什么盲区 |
|---|---|---|
| official | practitioner, quant | 执行/真实成本/隐藏费用 |
| quant | adversarial, practitioner | 误差/反例/定性成本 |
| practitioner | official, quant | 规则/统计代表性 |
| adversarial | official, quant | 正面证据/正常路径 |
| structural | historical, practitioner | 变化/地面真相 |
| historical | official, structural | 当下状态/结构解释 |
| regulatory | official, practitioner | 主体口径/合规实操 |
| academic | practitioner, quant | 可执行性/数据 |

配对不是强制闭包：`pairs_with` 写的是**首选接住者**；运行中可以用「本题不 material」或
「单镜风险已接受」替代（v2 §5.5）。
