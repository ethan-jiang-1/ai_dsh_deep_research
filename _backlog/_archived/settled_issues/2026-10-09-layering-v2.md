> 立卡：2026-10-09 ｜ 状态：已结——四件套落地且三活暴露面结构收口（解析器 = A：TS 解析器移植，用户拍板推翻原"不采纳"条目——前提被探查证伪）；证据与去向 = [layering-v2 Note](../../../notes/implemented/2026-10-09-layering-v2.md) ｜ 类型：Task ｜ 可关闭：是

**问题与期望结果：** [layering.test.mjs](../../../tests/contracts/layering.test.mjs)（纯文本 regex ×8）对照 company@59551f2 的四件套有三处真实缺口。出处 = [company 钉版复核 Note](../../../notes/implemented/2026-10-09-company-repin-review.md)（候选③）。期望：禁物判法不漏不误、tests 不再能 import 检查驱动（传递引入子进程目前纯靠约定）、test 命令形状被机械钉住。

**当前情况：** 三缺口——
1. **禁物判法窄**：动态 `import('playwright')`（无 `from` 前缀）与密钥间接引用（`const k = '…_API_KEY'`）逃检；同时 `fetch(` 文本正则会误咬夹具字符串（company 已弃用该形态改 AST）。company 现行 = 「任意提及」级 regex（playwright / 密钥名 / credentials.yaml）+ spawn/exec/fetch 族 AST 解析；
2. **import 图守卫缺席且有活暴露面**：`tests/contracts/verify-gates.test.mjs` import `scripts/smoke/gates-smoke.mjs`（顶层 import child_process，仅靠 argv 守卫才不在回归层起进程）——company 点名风险形态：「import 进来会把 spawn/fetch 整条带进回归层，文本扫描看不见传递引入」；
3. **package.json `test` 命令无机械钉**：node --test glob 即测试发现配置，被改宽/改坏无人拦。

**未决问题（2026-10-09 探查后收窄，事实见下节）：**
1. **解析器路径二选**（等用户拍板——选项 A 推翻本卡一条"不采纳"，前提被探查证伪）：**A** 移植 company `keyless-imports.mjs`（`import ts from 'typescript'`，typescript@6.0.3 已在根 node_modules 在场——非新依赖）；**D** 手搓受限括号配对解析（零依赖零加载开销，但边界形态漏判 = 假安全，且违研发宪章"循而不发明"）。倾向 A。
2. **import 图禁令范围**（探查后可定）：tests 禁 import `scripts/(smoke|probe|run-ops|run-gates|dist|verify)/` 驱动面，`scripts/lib/` 白名单；**活暴露面实为三处**（探查新发现：`evidence-audit.mjs`、`node-gate.mjs` 顶层 spawnSync，加卡已知 gates-smoke）——结构解法 = 被消费纯函数 lib 化（与 CASES 迁 lib 同型）。
3. **CASES/CONTROLS 迁 lib 的 git 障碍已解**：案例的 `fixtureFile` 内嵌 `git add` 可移除——主流程 mutate 后统一 `git add -A`（clone 的 .git 副本在场；gitignored 文件天然不入，`md-links-untracked` 案例不受影响）→ 案例 mutate 全变纯 fs，lib 化后无禁物传递。
4. 纪律有家句（company it#4 同款，对 guides/60 §2 / tests/AGENTS 的存在性断言）——随主件顺带。

## 探查实录（2026-10-09，只读核对 company@59551f2 与本仓现状）

- **company 的"AST 判法" = `tools/lib/keyless-imports.mjs`，解析器就是 typescript 包**（`import ts from 'typescript'`；`ts.createSourceFile` + AST 遍历，纯函数不执行；API = parseKeylessImports / isForbiddenKeylessModule / localImportPath / inspectKeylessGraph——跟随本地字面量 import 含再导出与动态 import，npm 包名不进本地图、只记 unresolved 观测）。
- **company 的 keyless 判据 = 运行时禁，非零 npm 依赖**：FORBIDDEN_MODULES = child_process/http/https/net/dgram + FORBIDDEN_CALLS = spawn 族/exec 族/fetch + 直呼 exec——typescript 作为解析库在其 keyless 缝隙（tools/lib）里合法存活。本卡"不采纳：引入 typescript compiler 进默认回归（违 keyless 纪律）"的前提与此不符；真实成本只剩 layering.test.mjs 每次回归加载 TS 的时长（当前回归纯跑 ~1.3s，预计 +0.5–1.5s，仍秒级）。
- **本仓 typescript@6.0.3 已在根 node_modules 在场**（root devDep `^6.0.3` + pnpm-workspace catalog `>=5 <7`；pack build 本来就用）——选 A 不是新增依赖。
- **company 四件套结构**（tests/harness/layering.spec.ts，直接移植模板）：it#1 禁物 regex 任意提及级（child_process import / playwright 提及 / 密钥名 + credentials.yaml）——fetch/spawn/exec 不走 regex（防夹具误咬），走解析后的调用表达式；it#2 test 命令钉（scripts.test 精确值 + 配置文件防线）；it#3 import 图守卫（regex 拦 tests import 驱动面 + inspectKeylessGraph 查 lib + unresolved 白名单 + 驱动头注声明"不进 pnpm test"）；it#4 纪律有家句存在性断言。
- **本仓活暴露面实为三处**（卡上只知其一）：`tests/contracts/verify-gates.test.mjs` import `gates-smoke.mjs`（spawnSync）；另有两处探查新发现——tests import `run-gates/evidence-audit.mjs` 与 `run-gates/node-gate.mjs`（两者顶层 `spawnSync`）。`run-gates/schema-scan.mjs` 与 `run-ops/run-dashboard.mjs` 为纯 fs（lib 形态住驱动目录——被消费纯函数可整体 lib 化）。
- **tests→lib 传递禁物现状 = 干净**：现有 14 个 scripts/lib 消费模块（含本仓自建全量）零 child_process/playwright/fetch 传递——import 图守卫落地不会误咬存量 lib 消费。
- **本仓 test 发现配置**：`package.json scripts.test = "node --import tsx/esm --test tests/*.test.mjs"`（精确串可钉；无第二配置文件面）。

## 方案与取舍

- **推荐候选**：探明解析路径后一次窄切片（layering 重写 + CASES 迁 lib/ + test 命令钉 + gates-smoke/verify-gates 连带改）。
- **不采纳**：引入 typescript compiler 进默认回归（违 layering 自身的 keyless 纪律）；照抄 company 的「任意提及」regex 全套（密钥名任意提及会咬 tests/AGENTS 的纪律文本自身——需按本仓文本实测校准误报率）。
