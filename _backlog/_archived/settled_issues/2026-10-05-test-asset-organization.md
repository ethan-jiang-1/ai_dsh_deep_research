## 背景 / 触发

用户 2026-10-05 提问：单元 / 集成 / 端到端等测试资产如何组织，"起码有一个套路，不能太随便"。本轮 session 实查判定：本仓已有**三轴组织**（2026-10-04 test-strategy 采纳时刻意的反金字塔设计）——档位轴（keyless ↔ 真模型，`layering` 钉死默认回归零外部依赖）、验收面轴（L0–L4，面面不互抵）、命名即层轴（`*.test.mjs` / `*-smoke` / `*-probe` / `*-gate·audit·scan`，文件名即申报），外加 fixtures taxonomy 与任务型路由表。真缺口 = 传统词汇对照桥与新检查落家序的单一入口；用户裁定入卡深想（金字塔比例 / 成本档位策略 / 覆盖面账），不做直派小修。

### 未决点

1. **词汇桥**：传统 unit / integration / e2e ↔ 本仓形态的对照表落不落、落哪（project-map §测试怎么选最顺；tests/AGENTS 预算顶格）；
2. **落家序**：六步决策序（契约测试 → 冒烟 → 真模型档 → verify 门禁 → run 门 → fixtures）收拢成单一入口文档，还是维持四处分散 + 本卡持有；
3. **比例与成本**：各档位触发频率与成本曲线（每 commit 秒级 → 按改动面 → 里程碑级）要不要成文为显式选层策略；升档判据（"失败先定位层再扩大范围"原则）够不够；
4. **覆盖面账**：要不要任何形式的覆盖登记（反对：清单必腐；支持：驾驶盲区不可见）——折中候选 = 关键资产清单住 discipline-map，或显式判"不做"；
5. **真模型档经济学**：L4-lite 等档的成本与触发节奏无量化，何时值得升档全靠判断；
6. **传统概念无落点者**（mutation testing、property-based 等）：要不要显式登记"刻意不做 + 理由"，防后人再问。

## 推敲结果（2026-10-05 深想轮，goal 驱动）

### 实验一：姊妹仓两文件通读（docs/testing.md + pre-push-evidence 技能 @ 576c5f8）

- **同职能异载体判定**：他们的"证据形态分层表（改什么 → 什么必须绿 → 家）"与本仓 [guides/60 §2 任务型路由表](../../../docs/guides/60-dev-loop.md) 同体裁同职能——路由表本体不缺；
- **他们更锋利的一点**：反金字塔理由——"同一标签下纯核与真 IO 的失败含义不同，**标签回答不了'要什么前置'**"；其双层寻址（后缀 = 车道，目录 = 被测 interface × 依赖半径，每层带"能证明 / 不能证明"列）是比本仓更细的组织轴；
- **三条本仓未成文的证据纪律**：①**互补案例规则**——断言是条件命题（"仅当 X"）时证据必须含非 X 案例，单一状态的证据集抓不到状态 bug（他们 2026-10-05 实案）；②**仪器对准目标而非跑者**——检查扫错 home 会拿无关残留凑绿（本仓 evidence-audit 锚定 dev home 自拒是同精神实例，未成文为通则）；③**新增测试资产形态先入词汇表再落文件**（他们由 verify 门机械执行）；
- **不借**：他们"commit 须读 exit code + 数 FAIL 行"教训（两次红 commit 实案）——本仓 pre-commit 钩子已机械化且更强（本 session 实拦一次）。

### 实验二：落家序三例回放（本 session 真实改动）

| 案例 | 六步序判定 | 结果 |
|---|---|---|
| navigability-contract.test.mjs（新 keyless 契约检查） | 第①步无歧义选中 tests/ | 过；暴露缺口：序未携带"同 diff 在 evaluation.md 对应面登记"义务（tests/AGENTS 有、序没链） |

结论：六步序 → **七步修正版**（补一次性检查步 + 各步挂登记义务 / 子程序指针）。

### 六个未决点裁决

1. **词汇桥**：落 project-map §测试怎么选——对照表 + 反金字塔理由（借姊妹仓措辞）；
2. **落家序**：收拢同节——七步修正版；
3. **比例与成本**：只成文一句原则（穷举矩阵不是目标，能咬中本次回归的红灯才是）；完整成本曲线判**不成文**（无数值数据先成文 = 假牙齿，floor 教训同源）；
4. **覆盖面账**：判**不做**（清单必腐；面覆盖归 evaluation 验收合同；触发器 = 首处"删了才对"死代码实证）；
5. **真模型档经济学**：判**维持判断制**（路由表"改动则跑 / 里程碑"已是节奏；触发器 = 某档频度漂移造成实际成本疼痛实证）；
6. **无落点概念**：mutation testing、property-based 判**刻意不做**；姊妹仓"目录即 interface"分层判**不现在建**（触发条件 = tests/ 检索开始靠猜或文件数显著上升）。
