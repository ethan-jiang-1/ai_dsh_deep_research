# _backlog/ · 状态机与把门规则

> 只收需澄清/查证/判断的工作；不是实施前置门，不授予实施授权（D19/D24）。用户直派按其范围执行。
> 本页 = agent 协议：frontmatter、状态机、下一步、审查、归档。工作路径/目录归属 = [README.md](README.md)；
> 卡片模板/初始 frontmatter = [issues/README.md](issues/README.md) · [bugs/README.md](bugs/README.md) · [research/README.md](research/README.md)；方法 = [methods/](methods/README.md)。

## frontmatter（status 首字段）

- issues：`status`、`opened`；bugs：`status`、`severity`、`opened`。
- research 题名页：`status`、`opened` + banner `> 状态：`；材料仍 `topic`、一行 `intent`，**不设** status。
- `status` = 当前阶段唯一家；状态行 `> 状态：` 镜像并记历史；目录只分活跃/归档。

## 状态 = 门，不是计时器

| 段 | issue | bug | research 题 |
|---|---|---|---|
| 研究 | `推敲中` | `排查中` | `调研中` |
| 定性（ready） | `待落地` | `修复就绪` | `已定性` |
| 落地 | `待落地` 期间 | `修复落地` | 结论转卡/Note |
| 审查/验收 | `等人拍板`（按重要性） | `修复落地`（判据/证据） | `已定性`（证据评审） |
| 归档 | `已结` | `已修` | 目录 + `> 归档：` |

侧态：`等人拍板`（任何活跃态等用户；只有用户能移动）、`叫停`（issue）、`待修`（bug）。

## 状态即下一步

- `推敲中` → 查证/收敛；`现在做` 票齐 → `待落地`；`以后做/不做/并入` → `已结`（去向）；缺用户判断 → `等人拍板`。
- `待落地` → 选去向（`proposed` RFC / `implemented` Note）；**不是授权**；交付/载体成立 → `已结`。
- `排查中` → `修复就绪`（根因 + 修法 + 判据；P1/P2 授权，P0/触面 → `等人拍板`）；`修复落地` → 跑判据/记证据/审查 → `已修`。
- `调研中` → 结论写进 `> 结论：` + `产出的卡` → `已定性`；无活跃消费者 → 整目录归档。
- `已结/已修` 只在归档池；与去向载体同变更；永不重开（复发 = 引用旧卡的新卡）。

## 翻转守卫（缺一不翻）

- `待落地` = `结论倾向：现在做` + 非空 `## 验收标准` + `去向`（proposed/implemented）+ 方案；只用于现在做。
- `修复就绪` = 根因证据 + 修法 + 非空 `## 修复判据`；P1/P2 修理型 = 修复授权；P0/入口链/门禁与验收合同/文档合同/pack 公共行为/D 号 → `等人拍板`。
- `已结/已修` = 审查/跳过已记 + 业务验收（如需）+ 去向载体成立 + 归档同变更；活跃卡 `可关闭：否`，`是` 只随归档翻转。bug 的 `修复落地`/`已修` 另须 `## 修复落地` 的 `改动`/`红证`/`绿证`（红证可重放或改动含测试/门禁资产），且 `改动` 与代码/测试同暂存集——只翻状态/移卡 = 假修（细则 = [bugs/README](bugs/README.md)；机械面 = `staged-change-pairing`）。
- `已定性` = 结论 + 证据评审 + `产出的卡` 已链；归档靠目录，不设独立状态。

## 审查（可跳，不可静默）

机械门禁/测试不跳；语义自审按风险（入口链/门禁与验收合同/文档合同/pack 公共行为/D 号/P0-P1 必审）；
用户验收按重要性（P0/公共行为/业务结果/阶段边界请用户）；跳过记 `审查：跳过 — 理由`，不写成 verified；Note 验证节只收实际证据。

## 沉默与归档

沉默不翻转；只有用户答复移动 `等人拍板`，只有用户叫停/复活。归档 = `git mv`，文件名不改、正文不重写；
状态行带 🔒 的触发只有用户能判。
