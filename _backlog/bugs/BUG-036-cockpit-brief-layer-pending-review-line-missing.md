# BUG-036：驾驶舱摘要层缺「审查未决项已按上限升级到本次审阅」一行（BUG-033 同族，自然复现 1 次）

## 症状

`client-load-smoke` 的「业务摘要层 = 盘侧 brief-fold 真值（五问逐行对账）」红：

```
FAIL 业务摘要层 = 盘侧 brief-fold 真值（五问逐行对账）（缺行：审查未决项已按上限升级到本次审阅）
```

现场：本轮 bound session = `drt_cambricon-commercial-sustainability`（P6-a A/B run，标准深度，review 有未决项
按上限升级的记账）；同跑其余摘要层断言与状态面断言（证据计数、交付状态、停靠点诚实线、问题行）均 PASS。

## 与 BUG-033 的关系

- BUG-033（[已修](../_archived/fixed_bugs/BUG-033-cockpit-brief-layer-intermittent-missing-delivered-lines.md)）
  的症状 = 缺"已交付态"三行，机制 = **读点部分水化**，闭环用**合成确定性红**取得；
- 本卡症状 = 缺**另一条**分支文案（`delivered === false` + 审查未决项升级态），同族但不同分支；
  BUG-033 的合成红没覆盖到这条分支 → 本次是它的自然复现补集。

## 根因分流（2026-10-18 实测，已收敛到两条同源缺陷）

现场 bundle = `drt_cambricon-commercial-sustainability`（review.md 225 行；第 2 轮 PASS 写在**标题行**
`# 第 2 轮（复审）—— readiness: **PASS**`，文末附录保留第 1 轮 `## 第 1 轮 readiness: FAIL`）。实测：

| 读法 | `terminalReadiness` | 说明 |
|---|---|---|
| 全量（盘侧期望侧 `client-load-reference` 直读文件） | **FAIL** | 判据取"最后一条"→ 文末附录的第 1 轮 FAIL 夺权 |
| 前 40 行（**UI 现状**：`props.readFile` 走默认 40 行） | **null** | 判据要的行落在窗口外 → UI 不渲染该行 → 与期望对不上（红得对） |

两条同源缺陷：
1. **UI 读 `review.md` 走默认 40 行 → 静默截断**（BUG-026 同族；判据要的是全文里的终局行，不限位置）；
2. **判据语义**：附录里**独立成行**的旧轮判定会被当终局（本 bundle 第 1 轮 FAIL 夺权）。既有回归测试
   （`terminalReadiness` 的"终局 PASS + 文末附录血统""行内引用不当判定"等 3 例）钉的是**行内引用**形态，
   **独立成行的旧轮标题形态未被覆盖** → 缺口在此。
