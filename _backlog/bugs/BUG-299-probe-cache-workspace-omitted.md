# BUG-299：probe 缓存键不含 `DSH_RUN_WORKSPACE`——换工作区可命中旧状态页 GREEN

>
> 探索轮 = [低置信区 20 卡（第 7 轮）](../issues/2026-11-18-low-confidence-20-round2.md)。

## 症状

run-driver 的探针读研究状态页/工作区数据；key 不含 workspace。不同工作区复用同一 pack/runtime 时，旧 GREEN 可被当作新工作区证据。

## 根因（已证）

工作区是页面数据身份，但不在缓存身份里。

## 复现

复现状态：稳定（读码/临时 fixture/局部脚本）。

```sh
# 证据见本卡症状与当前源码；临时验证只读，不改仓库
```

## 修法

1. 为该字段/入口补判据或缓存身份；
2. 加正反控与旧场/迁移豁免；
3. 与同类字段共用单一正本。

## 修复判据

- 该缺口有正反控；旧场/合法路径不误伤；
- `pnpm verify` / `pnpm test` 绿。
