# 探针手册：什么时候用、怎么加、证据在哪

> 层：指南。探针住根 [probes/](../../probes/README.md)；本页是「是什么 / 何时用 / 怎么写 /
> 证据与边界」的单一入口。每支探针的触发、判据与不证明归它自己的头注，本页不复制。
>
> 探针**不是第六个评估面**。评估五面（L0–L4）仍以 [evaluation.md](../evaluation.md) 为准；
> 探针是 L1/L4 的证据工具——在真实边界上对单一机制做可重复实验。

## 1. 是什么

**探针 = 在真实入口上，用最小场景制造一个特定状态，读取类型化证据，给出通过/失败判定，
并留下可离线复判的现场。**

它补的是单测与 E2E 之间的**归因空白**：单测看不见真实边界，E2E 红了不知道坏在哪一层。

| 层 | 回答什么 | 真实度 | 典型证据 |
|---|---|---|---|
| 单元测试 | 纯逻辑/纯函数对不对 | 低 | 返回值、错误 |
| **探针** | 某个机制在真实边界上是否按合同工作 | 中—高（真实入口） | 事件、真实文件、DOM、进程状态 |
| 冒烟 | 装没装上、通不通 | 高 | 启动成功、挂载零失败 |
| E2E | 整条用户链路通不通 | 最高 | 最终状态、截图 |
| 回放/金样 | 行为是否与录制/金样一致 | 高 | 会话日志、期望输出 |

三条原则：

1. **验证世界，不信自报**：断言从真实文件、事件流、外部观察取；被测方的自述、模型的解释、
   日志里的散文都不算证据。
2. **一支探针只证明一个命题**：命题越多，红了越难归因，最后退化成迷你 E2E。
3. **绿灯必须能被证伪**：每支探针都要有负例、对照或自证；没见过它红的探针，不算守卫。

## 2. 什么时候用

动手前先答三个问题；三个都答得上，才值得写：

1. **最低可观察层是什么？** 能不能不进 E2E？
2. **我能在几秒/几分钟内用真实入口造出这个状态吗？**
3. **失败时我能拿到什么不可抵赖的类型化证据？**

答不上第 2 条：先想办法让状态可控（临时目录/临时 home、屏障、假外部、固定时钟）。
答不上第 3 条：先补日志/事件/证据，再谈探针。

**症状 → 先看哪支**（完整清单 = [索引](../../probes/INDEX.generated.md)）：

| 症状 | 先看 |
|---|---|
| 模型不按纪律/角色回话 | [`discipline-probe`](../../probes/behavior/discipline-probe.mjs) |
| 入口链/授权口径漂移 | [`entry-chain-probe`](../../probes/behavior/entry-chain-probe.mjs) |
| Lead 不知道偏好库/条目 | [`method-library-probe`](../../probes/behavior/method-library-probe.mjs) |
| 驾驶舱页签/点击/交互坏 | [`cdp-probe`](../../probes/browser/cdp-probe.mjs) |
| 不满转接话术 | [`rerun-triage-probe`](../../probes/behavior/rerun-triage-probe.mjs) |
| LLM 流异常、要归因 | [`llm-stream-tee`](../../probes/stream/llm-stream-tee.cjs)（仪器，先取证） |

**不要用探针做的事**：纯函数/纯逻辑 → 单测；装配/安装 → 冒烟；完整用户旅程 → E2E；
内容质量/文风 → L4 或人读。

## 3. 目录与索引

```
probes/
  README.md              ← 门户：规则 + 指针，不手枚举
  INDEX.generated.md     ← 生成物：按域分组，列一句话/档位/触发/状态
  _index.mjs             ← --write / --check
  behavior/              ← 真模型行为：entry-chain / discipline / method-library / rerun-triage
  browser/               ← 真浏览器交互：cdp-probe
  stream/                ← 流取证仪器：llm-stream-tee（不判 PASS/FAIL）
```

- **域 = 第一级子目录**：域是一组共享 harness、共享证据来源、共享失败模式的机制；域内平铺
  `<mechanism>-probe.mjs`，不按 unit/integration 分。现在三个域 = 真模型行为 / 真浏览器 /
  流取证；新域先问「它和现有域共享 harness 吗」，没有就新建。
- **头注是唯一事实源**；索引只投影（一句话/档位/何时跑/状态），不复制判据与不证明全文。
- 索引与目录不一致 = 红。重生成：`node probes/_index.mjs --write`；校验：`--check`。
- **勿手改** `INDEX.generated.md`；新增/改名/删除探针必须重生成。
- 探针之间不互相 import；共享纯函数放 `scripts/lib/`（如 `probe-index.mjs`、
  `probe-send-target.mjs`），真实驱动放 `scripts/lib/` 的 driver 面。

## 4. 头注协议

前 16 行内必须有必填六字段（`为什么存在` 推荐）：

```js
// 探针：<name>
// 状态：常驻 | 已耗（YYYY-MM-DD 原因/复跑条件）
// 一句话：<证明的那一个命题>
// 何时跑：<具体触发条件>
// 档位：真模型（REAL_MODEL）| 连已起 GUI | 活进程仪器
// 判据：C1 …；C2 …
// 不证明：<故意不覆盖什么>
// 为什么存在：<推荐；事故/担忧/歧义>
```

- `何时跑` 越具体越好：改了什么、什么时候必须重跑。
- `不证明` 不是免责声明，是防止别人把绿读大；没有它，探针会变成新的假绿来源。
- `档位` 申报凭据与调用模式：真模型档必须登记在
  [smoke-contract](../../tests/contracts/smoke-contract.test.mjs) 的 `REAL_MODEL` 闭集。
- 端口：每个脚本独占固定端口（`scripts/AGENTS §端口与临时路径自持有`），由 `port-exclusive`
  门禁把守；不要改成 `--port 0`。

## 5. 新增一支（四步）

1. **先红**：改坏夹具、去掉保护或加负例，证明判据真的会红；还原后绿。只交付绿 = 不知道它会不会咬人。
2. **隔离/端口**：临时目录/临时 home；端口独占；结束清理（`--keep` 才留现场）；拒绝碰日用 home。
   **工作区夹具**：D40 后包不再播种 workspace 种子，`scaffold.mjs` 也已移除；探针用
   空工作区或自建 bundle，不要引用已删除的 pack 种子。零工具 prompt 可避免 read/bash 审批把
   探针挂起；此时模型答「未核实」是诚实态，判据应接受它、只拦编造。
3. **证据落盘**：`runtime/smoke-workspace/<probe>-<timestamp>/`；verdict + 原始日志/页面文本/截图；
   离线拿同一份证据重跑判据仍得同样结论。只有要冻结成金样才进 `snapshots/`。
4. **登记**：补头注六字段 → `node probes/_index.mjs --write` → `pnpm verify` 绿；
   `probe-registry` 门查头注、索引字节一致与 `probes/README` 链接。

**前置自检**：真模型/浏览器档先 `source dev/env.sh`；探针只认**开发 home**（默认
`runtime/harness-home`，或 `DSH_DEV_HOME` 指定的隔离实例）。ambient `DSH_HOME=~/.dsh` 是日用
平台 home，不是 dev home → exit 2 自拒，不 boot；否则会 boot 到平台 home 再以 exit 1 崩，
把「未跑」冒充成「红」。

退出码：`0` 全绿 / `1` 断言红 / `2` 前置缺席（未跑）。`SKIP ≠ PASS`；未跑 ≠ 通过。
重试只许在真模型/浏览器等外部边界，且带理由；确定性检查加重试 = 掩盖竞态。

## 6. 生命周期

- `状态：常驻` = 现在仍应该跑；触发见 `何时跑`。
- `状态：已耗（YYYY-MM-DD 原因/复跑条件）` = 一次性迁移/实验已完成；保留文件作历史，
  不再默认跑。**不要静默删除**——删除会让「当时为什么这么做」一起消失。
- 一次性实验**不进** `probes/`：留 `_backlog` / `notes`；同一个不确定性**复现第二次**才升格为
  入库探针。
- 已耗探针仍进索引（状态列可见）；门禁不要求删。

## 7. 覆盖地图

目录就是覆盖地图。某个失败面很薄/空白时，先问「是还没坏过，还是没人看」。

| 失败面 | 现有探针 | 备注 |
|---|---|---|
| 入口/授权/开发环路由 | `entry-chain-probe` | 真模型；词面 + 原文留档 |
| 纪律行为（A2/B1/收活/计划卡） | `discipline-probe` | 真模型；语义仍需人读 |
| 偏好库可发现性 | `method-library-probe` | 真模型；BUG-042 判据 |
| 不满转接 | `rerun-triage-probe` | 真模型；五条行为 |
| 驾驶舱交互/页签/发送 | `cdp-probe` | 连已起 GUI；`--ask` 按会话档 |
| LLM 流取证 | `llm-stream-tee` | 仪器；不判 PASS/FAIL |
| 并发/竞态、重启恢复、安装组合 | —（暂无专用探针） | 现有证据 = L1/L2 / client-load / 真 run；补探针时优先考虑 |

新 bug 落在哪个失败面，先补哪一面的探针。

### 7.1 类型地图（选型用）

类型按「证明什么」分，不按技术栈分。本仓当前覆盖在右列；空白不等于缺口——先问这个机制会不会坏。

| 类型 | 回答什么 | 典型场景 | 本仓当前 |
|---|---|---|---|
| 机制/状态机 | 状态迁移、终态、幂等 | 取消、重试、恢复 | 暂无 |
| 契约/边界 | 请求/响应/错误/超时 | RPC、文件 CAS、provider | 暂无 |
| 并发/竞态 | 交错时一胜一拒、零静默互踩 | 双写、认领 | 暂无 |
| 故障注入/恢复 | 取消、SIGTERM、重启后收敛 | 通道重启、流断开 | 暂无 |
| 组合/挂载 | 真宿主真加载了吗 | preset 挂载、client 装配 | L1/L2 smoke（不是探针） |
| 视觉/渲染 | 看得见、会更新、不挤爆 | 页签、面板 | `browser/` |
| 会话/上下文 | 注入/时间/预算/HITL 是否按规则 | 时钟、签字、停点 | `behavior/`（部分） |
| 行为/决策 | 规则/纪律在真模型下被遵守 | 纪律、转接、偏好 | `behavior/` |
| 审计/盘点 | 真盘面/日志符合规则 | 质量环、交付盘点 | run-gates（不是探针） |
| 回放/评估 | 录制行为可复现 | 会话回放 | snapshot-replay（不是探针） |

## 8. 边界

- 探针不替代 E2E，也不替代完整 run；它证「某一层」。
- 真模型探针只证一次行为，不证长尾说法不误判；结果要人读留档。
- 真模型/浏览器档成本高，不进 CI；`何时跑` 是唯一的重跑合同。
- 探针是开发资产：不进发布包；证据默认 `runtime/`（可清），冻结证据才进 `snapshots/`。
- 外部借镜（company 的 `probes/`、`/tmp` playbook）已按本仓约束改造：不搬 68 支/四域名/
  65 道门/`--port 0`；详见 [研究材料](../../_backlog/_archived/research/probe-surfacing/2026-11-10-probe-surfacing.md)。
